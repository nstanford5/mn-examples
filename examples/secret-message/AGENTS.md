# AGENTS.md — secret-message

**Verified against:** Compact language `0.23`, compiler `0.31.1`,
`@midnight-ntwrk/midnight-js-*` `4.1.1`, wallet SDK `1.2.0`, Node 22.

## What it teaches

- Keeping data private on-chain by publishing a **hash commitment** instead of
  the value — the step up from `hello-world`'s public message.
- Sourcing a private value from private state via a **witness**
  (`secretMessage`), and doing off-chain encoding (string → `Bytes<32>`) in the
  witness where the circuit can't.
- Passing a witness value into a circuit through a parameter, hashing it with
  `persistentHash<Bytes<32>>`, and why `disclose(...)` is required to write a
  witness-derived value to the public ledger.
- That `persistentHash` cannot hash `Opaque` values (the circuit can't see their
  bytes) — the message must be a transparent, hashable type.
- Using an `export`ed pure circuit (`hashMessage`) from TypeScript via
  `pureCircuits` to recompute and verify a hash commitment off-chain.

## Layout

- `contract/secret-message.compact` (committed), `contract/index.ts`
  (+ `contract/witnesses.ts` when the contract declares witnesses).
- `src/` harness; `src/test/secret-message.test.ts`.

## Run

```bash
yarn compile
yarn env:up && yarn wait:dust
yarn test:local
yarn env:down
```

## Notes for agents

- `contract/managed/` is generated by `yarn compile` and gitignored. The TS
  harness imports from it, so nothing type-checks until you have compiled at
  least once.
- The circuit-id union in `src/providers.ts` is derived from the compiled
  contract (`keyof ImpureCircuits`), so it never needs editing when circuits
  change.
