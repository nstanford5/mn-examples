# AGENTS.md — calculator

**Verified against:** Compact language `0.23`, compiler `0.31.1`,
`@midnight-ntwrk/midnight-js-*` `4.1.1`, wallet SDK `1.2.0`, Node 22.

## What it teaches

- A single **public `ledger` value** (`result: Uint<16>`) updated by circuits.
- Basic arithmetic circuits: `add`, `subtract`, `multiply`, `square`.
- The **verify-off-chain-work pattern**: the `divide` circuit calls the `divMod`
  witness (off-chain integer division in `contract/witnesses.ts`), re-verifies
  it on-chain with `assert`, and stores the quotient in `result`.

## Layout

- `contract/calculator.compact` (committed), `contract/index.ts`,
  `contract/witnesses.ts` (implements the `divMod` witness).
- `src/` harness; `src/test/calculator.test.ts`.

## Notes on `divide`

- `divide` must write to the ledger (`result = disclose(quo)`) to be a
  proof-generating, on-chain circuit. A version that only `return`s the quotient
  is compiled `proof: false` (no ZK key, no state change) and is not submittable
  via `submitCallTx`.
- Returning/storing the witness-derived `quo` requires an explicit `disclose()`.

## Run

```bash
yarn compile
yarn env:up && yarn wait:dust
yarn test:local
yarn env:down
```

## Notes for agents

- `contract/managed/` is generated by `yarn compile` and gitignored. The TS
  harness (`contract/index.ts`, `contract/witnesses.ts`, the test) imports from
  it, so nothing type-checks until you have compiled at least once.
- The private-state type is empty (`Record<string, never>`) — the calculator
  keeps no private state; `divMod` is a pure witness.
- All five circuits (`add`, `subtract`, `multiply`, `square`, `divide`) are
  exported and proof-generating; the callable set lives in `src/providers.ts`.
- `ui/` is a browser frontend generated by `yarn new:ui calculator`. Only its
  seed files are calculator-specific: `src/midnight/calculator-api.ts`
  (`result$`, the `OPERATIONS` table, `evaluate()`),
  `src/components/calculator-panel.tsx`, and the tests
  `src/__tests__/calculator-circuits.test.ts` and `operations-card.test.tsx`.
  Everything else is template-owned (see `ui/AGENTS.md`).
  If you change what a circuit accepts, update `evaluate()` as well. The
  circuits test checks it against the compiled circuits and fails when they
  disagree.
